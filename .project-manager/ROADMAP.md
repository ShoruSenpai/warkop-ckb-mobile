# Roadmap Proyek

Urutan tahap berikut dipertahankan sesuai arahan developer.

1. **Tahap 1 - Project Initialization** - selesai. Scaffold, struktur, dependency dasar, theme, navigasi contoh, responsive foundation, preview, dokumentasi, analyze, test, dan Android debug build terverifikasi. Tidak ada Android device/emulator untuk click-through langsung.
2. **Tahap 2 - Core Architecture** - belum dimulai. Pematangan provider, repository, error handling, session, network/security/storage contracts sesuai kebutuhan.
3. **Tahap 3 - Routing & Workspace** - belum dimulai. Authentication flow, role/workspace resolution, guard, dan registry workspace.
4. **Tahap 4 - Responsive Framework** - belum dimulai. Layout final mobile portrait serta tablet portrait dan landscape.
5. **Tahap 5 - Employee Workspace** - belum dimulai. Home, presensi, Profile, dan alur presensi sesuai keputusan bisnis.
6. **Tahap 6 - Cashier Workspace** - belum dimulai. Standby, verifikasi PIN employee terjadwal, POS, dan navigasi kasir.
7. **Tahap 7 - Data & Offline** - belum dimulai. Penyimpanan lokal terbatas, antrean outbox, retensi, serta retry.
8. **Tahap 8 - API Integration** - belum dimulai. Integrasi hanya sesudah audit API Laravel dan persetujuan developer.

Perubahan urutan memerlukan alasan dan persetujuan developer. Tahap berikutnya hanya dimulai setelah instruksi baru.
