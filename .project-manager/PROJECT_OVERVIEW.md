# Project Overview

Warkop Cak Kebo Mobile adalah satu aplikasi operasional Android untuk smartphone dan tablet dengan workspace Employee, Cashier, Admin, dan Owner.

## Tujuan

Menyediakan aplikasi klien untuk aktivitas operasional. Laravel tetap menjadi sumber kebenaran untuk autentikasi, permission, PIN, jadwal, presensi, geofence, harga, stok, transaksi, dan pembayaran.

## Batas Tahap 1

Tahap ini hanya menyiapkan project Flutter, arsitektur dan folder, Riverpod, GoRouter, registry navigasi contoh, responsive/orientation foundation, design tokens, komponen global, preview sementara, dan dokumentasi. Belum ada login, fitur bisnis, request API, database lokal, atau sinkronisasi.

## Platform dan SDK

- Target pertama: Android smartphone dan tablet.
- SDK yang ditemukan: Flutter 3.47.2 stable, Dart 3.13.2.
- Constraint SDK proyek tetap `^3.13.2`.
- Android SDK tersedia; audit rinci dan keterbatasan perangkat dicatat di `PROJECT_STATUS.md`.

## Identitas aplikasi

Package Dart: `warkop_ckb_mobile`. Application ID Android scaffold saat ini `com.example.warkop_ckb_mobile`; dipertahankan selama Tahap 1 karena tidak ada instruksi untuk menggantinya.
